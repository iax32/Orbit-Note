# Publishing fonts

Lato and Crimson Text regular, bold, italic and bold italic fonts are bundled
for offline PDF publication. Retrieved from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/lato
- https://github.com/google/fonts/tree/main/ofl/crimsontext

Their SIL Open Font License notices are retained in `lato-OFL.txt` and
`crimsontext-OFL.txt`. Font files are unmodified.
