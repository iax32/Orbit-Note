# Product vision

Orbit Note is an open-source, local-first personal knowledge operating system:
one workspace in which writing, structured planning, visual thinking, and drawing
work with the same knowledge. It is an application, not an operating-system kernel.

Borrow the strengths of Obsidian (links and file ownership), OneNote (freeform
pages and pen input), Milanote (spatial organization), and Notion (properties and
multiple views). Give those capabilities one coherent data model and interaction
system. Avoid four independent content stores behind four tabs.

## Core promise

**Any object, multiple useful views.** A project can appear in a Markdown document,
collection, table, calendar, board card, and graph without becoming six copies.
Views show an object where its capabilities make sense; a PDF need not become a
text editor merely because objects share identity.

A learner captures a lecture, attaches a PDF, draws on a freeform page, links a
concept, and extracts a task. A builder places existing project notes on a board,
connects decisions and assumptions, and follows the same tasks in a table. Both
can close the network connection and continue working with their own files.

## Audience and experience

Students, researchers, writers, developers, and people managing personal projects.
Fast capture and a calm default come first. Power users can progressively customize
navigation, panes, themes, keybindings, dashboards, and contextual Spaces. Mobile
adapts to touch and small screens rather than compressing the desktop interface.

The longer-term distinction is contextual memory: provenance, decisions, knowledge
history, work sessions, useful resurfacing, and organization suggestions with
explanations. AI is optional and provider-independent; changes are reviewable and
reversible. A user can leave with readable notes, original files, structured data,
drawings, and their relationships intact.

## Delivery discipline

The first usable loop is capture → save locally → reopen → find → link. Spatial
boards and structured views grow on that loop. Sync, plugins, advanced automation,
and collaboration follow durable local behavior. M0 establishes a small shell;
it does not implement the whole vision. See the [roadmap](../planning/roadmap.md).

For the precise audiences, core workflows and boundaries, read the
[product definition](product-definition.md) and [user journeys](user-journeys.md).
The product supports personal notes, study, research, development, reverse
engineering, game projects and eventually teams through one reusable knowledge model.
