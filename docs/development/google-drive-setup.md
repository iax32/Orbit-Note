# Google Drive setup

The maintained [Google Drive developer setup guide](google-drive-sync-setup.md)
covers Cloud project, consent/scope, Windows and Android client identities,
certificates, secure token custody and the public example configuration.

Current status: native Google account login/restoration, account UI, quota and
root/discovery are implemented and consume the example configuration keys.
Vault upload/download and automatic sync remain pending. Follow the guide to build
with your developer client configuration; unconfigured builds stay local only.
