# Backlink precision

Existing WikiLink, Canvas-card, task/event context and PDF citation snippets remain
available in the inspector. WikiLink targets retain their exact fragment; Canvas
card targets retain `referenceTarget`. Source clicks open a note source match or
Canvas element when available. Ambiguous/missing targets preserve written source.

No new canonical relation database is introduced. Text backlinks are derived.
See [references](../architecture/references.md) and the
[task report](../tasks/architecture-composition-2026-09-30.md).
